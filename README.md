# 🐾 VetZoo Control System

**VetZoo Control System** — это полнофункциональная веб-система для управления ветеринарным учетом в зоопарках. Система позволяет вести учет животных, их осмотров, прививок и рационов, а также предоставляет инструменты для планирования процедур и анализа данных.

## Возможности

### Многоуровневая система ролей
- **Администратор** — полный доступ к управлению пользователями и настройкам
- **Ветеринар** — управление медицинскими данными животных
- **Кипер** — просмотр информации о животных и их рационах

### Управление данными о животных
- Добавление и редактирование информации о животных
- Отслеживание статуса здоровья
- Проведение и планирование осмотров
- Учет прививок с возможностью планирования ревакцинации
- Управление рационами питания

### Аналитика и отчеты
- Статистика по здоровью животных
- Отчеты по вакцинации
- Графики и диаграммы
- Экспорт данных в JSON

### Система уведомлений
- Напоминания о предстоящих процедурах
- Визуальные индикаторы срочности
- Интегрированное расписание

## Локальный запуск

### Предварительные требования
- Python 3.8 или выше
- pip (менеджер пакетов Python)

### Установка и запуск

1. **Склонируйте репозиторий**
```bash
git clone https://github.com/yourusername/vetzoo-control.git
cd vetzoo-control
```
2. **Установите зависимости**
```bash
pip install -r requirements.txt
```
4. **Запустите**
```bash
cd server
python app.py
```
6. **Откройте браузер и перейдите по адресу**
```bash
http://localhost:5000
```
7. **Зайдите под учётной записью администратора, создаваемой по умолчанию**: admin / admin

Также предусмотрена возможность запуска через Dockerfile.
